# 澳門土地用途地圖

**規劃 × 現況｜全澳土地資料查詢**

將全澳官方規劃、公開地段、建築物及場所記錄，疊加到街道／衛星地圖查詢。頁面為繁體中文，支援電腦及手機。

## 使用

- 搜尋分區、地段、場所或建築物名稱。
- 切換全澳總規、A區詳規、公開地段及官方場所。
- 點選位置並列規劃用途和現況場所參考。
- 切換街道／衛星底圖，調校規劃透明度。
- 放大後顯示場所點位及建築物輪廓；建物資料按需要載入。
- 資料說明內可下載GeoJSON，並開啟官方來源。

## GitHub Pages

本專案沒有建置步驟。將GitHub Pages的來源設為 **Deploy from a branch → main → /(root)** 即可；根目錄已附`.nojekyll`。

本機預覽：在倉庫根目錄執行 `python3 -m http.server 8000`，開啟 `http://localhost:8000/`。

## 資料限制

- 本頁為固定快照，不會自動更新；個別記錄更新日期未提供，不能把擷取日期當成記錄更新日期。
- 官方場所分類與整幅土地實際用途不同；附近場所不代表同一地段或同一業主。
- 缺少場所記錄不代表空置、無用途或違規。規劃與場所分類不同，不能單憑本圖判定違規。
- 總規圖形面積為圖形估算，與官方地段面積分開；以有權限實體實測為準。
- 外部底圖需要網絡連線；衛星影像並非即時。

本網站並非政府官方網站。政府圖資及第三方底圖的權利屬原來源；公開此倉庫不代表就該等圖資授予新的再授權。
